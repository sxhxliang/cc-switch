# CC-Switch CLI

Terminal-based interface for managing Claude Code & Codex provider configurations.

## Features

- ✅ **Provider Management**: List, add, edit, delete, and switch providers
- ✅ **MCP Server Management**: Toggle, delete, import, and sync MCP servers
- ✅ **Keyboard-Driven TUI**: Fast and efficient terminal interface
- ✅ **Tab Navigation**: Seamlessly switch between Claude and Codex
- ✅ **Built-in Help**: Press `?` to see all keyboard shortcuts
- ✅ **Shared Backend**: Uses the same Rust codebase as the GUI version

## Installation

### Download Pre-built Binaries

Visit the [Releases](../../releases) page and download the binary for your platform:

- **Windows**: `cc-switch-cli-*-x86_64-pc-windows-msvc.zip`
- **Linux**: `cc-switch-cli-*-x86_64-unknown-linux-gnu.tar.gz`
- **macOS (Universal)**: `cc-switch-cli-*-universal-apple-darwin.tar.gz`
- **macOS (Apple Silicon)**: `cc-switch-cli-*-aarch64-apple-darwin.tar.gz`
- **macOS (Intel)**: `cc-switch-cli-*-x86_64-apple-darwin.tar.gz`

### Build from Source

```bash
# Clone the repository
git clone https://github.com/farion1231/cc-switch.git
cd cc-switch/src-tauri

# Build release binary
cargo build --bin cc-switch-cli --release

# Run the CLI
./target/release/cc-switch-cli
```

## Usage

Simply run the executable:

```bash
# Linux/macOS
./cc-switch-cli

# Windows
cc-switch-cli.exe
```

## Keyboard Shortcuts

### Navigation
| Key | Action |
|-----|--------|
| `↑` or `k` | Move up |
| `↓` or `j` | Move down |
| `Tab` | Next tab |
| `Shift+Tab` | Previous tab |
| `1` | Jump to Claude tab |
| `2` | Jump to Codex tab |

### Provider Management
| Key | Action |
|-----|--------|
| `Enter` | Switch to selected provider |
| `a` | Add new provider |
| `e` | Edit selected provider |
| `d` | Delete selected provider |
| `r` | Refresh provider list |

### MCP Management
| Key | Action |
|-----|--------|
| `m` | Enter MCP management mode |
| `Space` | Toggle MCP server (in MCP mode) |
| `i` | Import MCP servers from live config |
| `s` | Sync enabled MCP servers to live config |
| `d` | Delete MCP server (in MCP mode) |

### General
| Key | Action |
|-----|--------|
| `?` | Show help screen |
| `q` | Quit application |
| `Esc` | Cancel/Go back |

## Configuration Files

The CLI uses the same configuration storage as the GUI version:

- **Main config (SSOT)**: `~/.cc-switch/config.json`
- **Settings**: `~/.cc-switch/settings.json`
- **Backups**: `~/.cc-switch/backups/`

**Live configs** (generated by CC-Switch):
- **Claude**: `~/.claude/settings.json`
- **Claude MCP**: `~/.claude.json`
- **Codex**: `~/.codex/auth.json` + `~/.codex/config.toml`

## Architecture

The CLI is built with:
- [ratatui](https://github.com/ratatui-org/ratatui) - TUI framework
- [crossterm](https://github.com/crossterm-rs/crossterm) - Terminal manipulation
- Shared Rust backend with the GUI version

```
Main Loop (cc-switch-cli.rs)
    ↓ Event handling
App State (tui/app.rs)
    ↓ Uses
Shared Services (ProviderService, McpService)
    ↓ Modifies
AppState (RwLock<MultiAppConfig>)
```
